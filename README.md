制作人 **LinFeng**。在 chatgpt.com 页面里挂一块**可移动的浮动辅助面板**（PS 调板式），做亚马逊 A+ 时少切面板。

## v0.6.32：导入 GPT 的前缀能自己改

设置里新加一段「导入 GPT 前缀」：

- 两个输入框，默认是 `标题` / `辅助信息`，随便改成 `Product` / `Note` 这类，后面会自动补「：」；
- 一个「显示前缀」开关：关掉之后导入只输出内容本身（`Dishwasher Inlet Valve`），不带任何标签。

生效范围：模板里**只有占位符**（或只有「标签：占位符」）的那一行会按设置的前缀重写；行里还有别的文字时，模板原文不动，只替换占位符。模板没有占位符时，前置的两行同样走这套前缀。

同时把按钮文案从「导入 gpt」改成「导入 GPT」。

## v0.6.31：导入对话框用「标题 / 辅助信息」

主图模板里原本写的是「主体：{标题信息}」「补充信息：{辅助信息}」，A+ 模板里是「补充信息：」。导入到 ChatGPT 时这些字面标签会一起进去，跟面板上的「标题卖点 / 辅助信息」对不上。

现在两个字段统一成 **`标题：`** 和 **`辅助信息：`**，A+ / 主图两套模板都改了。模板里没有占位符时（比如白底主图），手动填的值也按这两个标签前置，不会再多一层「【标题卖点】」。

已经保存过旧模板的情况不用手动改：启动时会把「主体：{标题信息}」替成「标题：{标题信息}」、把「补充信息：{辅助信息}」替成「辅助信息：{辅助信息}」，只动这两处标签，模板其余内容原样保留。

## v0.6.29：设置里的开关能看出开关状态了

以前 `.on` 这个 class 只在页签上有样式，设置里的开关虽然内部记着状态，但按钮长相和没开一样，只能靠自己记。

现在统一了口径：**开 = 实心强调色底 + 白字 + 实心白点，关 = 透明描边 + 灰字 + 空心点**。功能开关（白底主图页签 / 大图时自动隐身 / 侧栏弹出时右让 / 左侧面板暂隐）都带这个状态点；文字大小、三栏比例、导出方式这类单选按钮也是选中即实心，跟开关同一个视觉语言。

强调色跟着面板设置的强调色走，换主题或换强调色，开着的开关会一起变色。

## v0.6.28 修正（沿用）

**让位时面板来回跳**

两处原因，都修了：

1. 之前用 `transform: translateX()` 做位移，但面板根节点上有 `transform: none !important`（防止网页样式污染它），这条规则优先级更高，位移根本没生效——面板看起来"动了半格又弹回去"。改用独立的 `translate` 属性，它不受 `transform: none` 影响。
2. 每 500ms 的重算会把位移反复"先清掉再加回"，而且算位置时读到的是自己平移后的坐标，越算越偏。现在改成**只算一次**：先记下当前位移量、把它从读数里扣掉再算目标位置，目标值和现状一致就直接跳过不动 DOM。

另外鼠标停在面板上时状态会被冻结——否则面板一让位、鼠标就落到面板上，又开始往回弹。

**暂隐时面板直接消失**

改成先 0.18 秒淡出到透明，再把 `visibility` 推迟切走；侧栏缩回时立刻恢复可见并淡入，不是硬切。开着拆分独立窗时，落在中线右侧的独立窗仍然保持可见。

## v0.6.27 改动（沿用）

ChatGPT 左侧的对话栏是鼠标移过去展开、移走折叠的，展开时会压在面板上。现在做了两条，各自一个开关，都在**设置 → 功能开关**里：

**侧栏弹出时右让（默认开）**

鼠标移到左侧对话栏那排图标、对话栏弹出来时，面板整体往右平移，正好让开侧栏；鼠标移走、侧栏缩回去，面板平滑回原位。平移用 `transform`，不动面板记录的 left/top，所以不会把位置改脏，缩放窗口后照样贴回设定位置。

判定用两条路：

- 量页面里贴左边缘、高度过半屏的侧栏元素宽度，≥176px 视为展开（顺便拿到真实宽度用于让位距离）；
- 兜底用鼠标热区：鼠标进到最左 76px 且不在面板上，视为要展开。

**左侧面板暂隐（默认关）**

开启后，按浏览器竖向中线判断：侧栏弹出期间，中心落在中线左侧的面板 `visibility:hidden` 暂时消失，右侧的保持可见；缩回即恢复。如果开了拆分独立窗，「主线」被隐掉时，落在右侧的独立窗会用 `visibility:visible` 单独保住，不会被父级一起藏。

两个开关可以都开：都开时先按「中线左侧 → 隐藏」，剩余右侧的再按「往右让位」，互不打架。

## v0.6.24 修了什么

**上一版「大图隐身」会把面板顶掉，导致面板像消失了一样**

v0.6.23 的判据太宽：只要页面上出现一块铺满视口的 `fixed` 容器就收面板。ChatGPT 页面里常驻着这类容器（应用外壳、背景层），于是面板一进页面就被判成「大图模式」藏起来。

现在收紧成三条同时满足才收面板：

- 铺满视口（宽高都 ≥ 86%）；
- 层级够高（z-index ≥ 20）；
- **里面真有一张铺开的大图**（img / canvas / video 渲染面积 ≥ 视口 30%），或者是带图的全屏图像模态（`role=dialog` + z ≥ 100）。

页面外壳、背景装饰层、没有大图的全屏模态，一律不再触发。

**加了「叫回」小点**

只要面板处于隐身状态，屏幕右下角会出现一个 30px 的小圆点（眼睛图标）。点它 = 关掉「大图时自动隐身」并把面板立刻放回来，同时这个开关会记住为关闭，避免反复被顶掉。重新打开：设置 → 功能开关 → 「大图时自动隐身」。

**如果你升级后完全看不到面板**，先确认两件事：扩展在 `chrome://extensions` 里是启用状态（无红色报错），并且**刷新过一次 chatgpt.com 标签页**——重新加载扩展不会自动往已打开的旧标签注入新的脚本。

## v0.6.23 改动（沿用）

**点开 GPT 的大图 / 详情弹层时，面板自动隐身**

以前点生成图进大图，面板正好压在画面上。现在检测到网页出现全屏弹层就把整块面板收起来（`opacity:0` + `visibility:hidden`，不占位也不吃点击），退出大图自动回来，不需要手动再点。

判定条件（保守，避免侧边栏、抽屉这类弹层误伤）：

- 是 `[aria-modal="true"]`、`[role="dialog"]`、`[data-testid*=overlay|lightbox|modal]`，或 `fixed/inset-0` 这类全屏容器；
- 实测矩形至少覆盖视口 86% 的宽和高；
- 自身是 `fixed` 或 `absolute`，且有实际可见性；
- 或者浏览器进入了 `document.fullscreenElement`。

命中时给出一次轻提示「网页进到大图里了，面板先收起」，6 秒内不重复提示。

**设置里可关**

设置 → 功能开关 → 「大图时自动隐身」，默认开；关掉后行为与以前一致。开关状态随其他设置一起存本地。

## v0.6.21 改动（沿用）

**右键「另存这张」终于和导出按钮同名同位置**

两个毛病叠在一起：

1. 右键时取的是「素材」那条记录，不是「收藏」那条 —— 素材记录上没有模块和备注，文件名就退回默认的「A+图」，甚至被浏览器按 URL 兜底成「下载1」。现在右键优先取收藏记录，文件名按「模块_备注」拼，例如 `主图02_阀体右下水痕.png`。
2. 另存没跟设置走。现在「另存这张」和「导出」共用同一套保存逻辑：设置选「每次问位置」就弹保存对话框（文件名已预填，位置自选，确定的目录下次还记得）；选「存下载夹」就走 Chrome 下载，落到 `A+导出/`。

另外补了退路：超大图（2048×2048 转 base64 后过长）走 Chrome 下载接口会失败，现在失败后自动改用页面内 blob 下载，名字照样生效，不会再出现无名文件。

素材本身（还没归模块、没写备注）右键另存时，用图自己的文件名，不再是「A+图」。

## v0.6.20 改动（沿用）

**修「移到组…」点了没反应**

根因很具体：全局 `pointerdown`（捕获阶段）负责「点别处关菜单」，判断条件只放过 `#apCtx`，没放过组选择菜单 `#apGrpPick`。于是真实鼠标点菜单项时，pointerdown 先把菜单隐藏，click 就落不到按钮上 —— 看起来就是点了没反应。判定条件改成 `#apCtx, #apGrpPick` 后恢复正常。

**素材支持多选**

- 单击图片选中（蓝框 + 右上圆点）；`Ctrl`（Mac `Cmd`）点击加选 / 取消；`Shift` 点击从锚点连选一片；点素材区空白取消全选。
- 选中状态显示在素材信息行：`3 张素材 · 已选 3 张`。
- 右键菜单跟着多选走：`移到组…（3 张）`、`移除选中的 3 张`；右键其中一张时若它已在多选里，整批处理，不会只处理一张。
- 归组菜单顶部会写「已选 3 张，归到：」，一次把整批移到目标组。
- 多选只在内存里，不写盘；刷新后是干净的未选中状态。

## v0.6.19 改动（沿用）

**素材加了「组」，像 PS 的图层组，用来区分类别**（原图 / 已修 / 待改 / 参考……）

## v0.6.18 改动（沿用）

- **修 Ctrl+Shift+1~9 版面预设快捷键失效**：原因很具体 —— 按住 Shift 再按 1，浏览器给出的 `event.key` 不是 `"1"` 而是 `"!"`（`@ # $ % ^ & * (` 同理），旧代码用 `/^[1-9]$/.test(e.key)` 判断，永远匹配不上，所以按了没反应。现在改用 `event.code`（`Digit1`~`Digit9` / `Numpad1`~`Numpad9`）判断，不受 Shift 影响，同时保留对 `1`~`9` 与 `!`~`(` 的兜底。
- **按空位时给反馈**：按了 Ctrl+Shift+N 但没存过第 N 套预设，现在会 toast「还没有第 N 套预设（设置里可存）」，不再静默无反应。

## 关于 ChatGPT 左侧会话栏被折叠成图标条

那是 ChatGPT 自己的响应式行为：可用宽度变窄时它会把左侧会话栏折叠。浮动面板只盖在页面上、不占布局宽度；侧栏仍折起时把窗口最大化即可。

## 装完看不到面板？按这个顺序查

1. **先刷新页面**：扩展装好后，已经打开的 chatgpt 标签页必须刷新（或关掉重开）才会注入面板。
2. **确认地址是 chatgpt.com**：面板只在 `chatgpt.com` / `chat.openai.com` 生效，其他站点不会出现。
3. **看控制台**：按 `F12` → Console，正常会有一行 `[A+工作台] 面板已挂载 · 宽度 Npx · chatgpt.com`。
   - 有这行但看不到 → 点「贴右」复位，或双击标题条确认不是折叠态。
   - 没这行 → content script 没执行，去 `chrome://extensions` 看扩展有没有报错（红色「错误」按钮点开看）。
4. 面板有**自动重挂**：页面若在初始化时清掉面板节点，1 秒内会挂回来。

## 安装（Chrome / Edge）

1. 把本压缩包解压到任意固定目录（解压后应能看到 `manifest.json`、`content.js` 等同级文件，不要再套一层）。

4. 点 **加载已解压的扩展程序**，选择刚才解压出来的文件夹。

## 面板里能做什么

- **标题卖点 / 辅助信息**：填一次，自动保存；导入时替换提示词里的 `{标题信息}` `{辅助信息}` 占位符。
- **三套提示词**：主图、A+、白底主图，各自独立保存，下次打开还是你的版本；白底主图这一页签可在「设置」里关掉。
- **版本**：起个名字存版本（最多 6 个），可随时切回；「对比」可看两个版本的行级差异（绿色新增、红色删除）。
- **插入片段**：把常写的约束（纯白底、不要文字、留安全区……）存成片段，点一下插到光标位置，不覆盖原文。
- **导入 gpt（只填不发送）**：把标题 + 辅助信息 + 当前提示词写进 ChatGPT 的输入框，**不会点发送**，也不改动已有对话。输入框已有内容时会先问你要不要覆盖。
- **提取页面图片**：扫描本页生成图（大于 120px、去重），点缩略图看大图，可「收藏这张」。
- **素材（本机参考图）**：点「导入图片」从电脑多选，缩略图排队；点图看大图，右键可复制（粘到对话框即上传）/ 加入素材 / 移除。存在浏览器本地库里，重启还在。
- **收藏 + 导出**：每条收藏可设模块（主图01–08 / A+01–05 / 主视觉…）和备注；导出时文件名自动是
  `序号_模块_宽x高_备注.png`，导出时选一个本机文件夹，直接写进去（存到下载目录 `A+导出/` 为回退方式）。
- **右键定稿 / 待选**：在 ChatGPT 对话里的生成图上右键，或在收藏行、素材缩略图、文档插图上右键，选「定稿 / 待选 / 设备注」。
- **面板配色与字号**：见上面「设置（二级面板）」，配色、强调色、字号都可调并记住。

快捷键：面板内 `Ctrl+Enter` = 导入。

## 已知限制（原型阶段）

- 不带文档解析：Word / PPT 里的标题文案仍需你自己复制（和之前商定的一致）。
- 文档里的表格暂按段落文本抽取，不做表格排版；Word 自动编号已支持，手打序号本来就跟随文本。
- 收藏只存图片链接：`blob:` 类型的图在页面刷新后会失效，**收藏后请尽快导出**；`https` 链接若过期也会下载失败。（本机素材不在此列——它存的是图片本体。）
- 导出走 Chrome 下载 API，首次可能弹「是否允许下载多文件」，允许多个即可。
- 面板读的是页面 DOM，ChatGPT 改版可能让「导入」找不到输入框；届时会提示「页面上没找到对话输入框」。
- 不包含自动提交、批量提交到卖家后台（违反 Amazon ToS）。
